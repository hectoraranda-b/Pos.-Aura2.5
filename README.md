Aura POS - Política de Privacidad y Términos del Servicio
Fecha de última actualización: Septiembre de 2026
1. Introducción
Aura POS es una aplicación de escritorio desarrollada para la gestión local de puntos de venta en negocios. Esta política de privacidad describe cómo se recopilan, utilizan y protegen los datos de los usuarios al utilizar nuestros servicios de respaldo en la nube.
2. Información que Recopilamos
Nuestra aplicación opera bajo un modelo de arquitectura local (offline-first). No almacenamos información personal, financiera ni de transacciones de los clientes finales en servidores externos o de nuestra propiedad.
3. Uso de la API de Google Drive y Dropbox
Aura POS integra conectores opcionales para servicios de almacenamiento en la nube de terceros (Google Drive y Dropbox) exclusivamente para las siguientes finalidades:
Respaldos Automáticos: Generar copias de seguridad cifradas de la base de datos local del punto de venta.
Almacenamiento Privado: Transferir dichos archivos comprimidos únicamente hacia una carpeta dedicada dentro de la cuenta personal o empresarial del propio usuario.
4. Seguridad de los Datos
Componente
Mecanismo de Protección
Credenciales OAuth
Gestionadas de forma local mediante archivos de entorno (.env) y tokens cifrados del cliente.
Tratamiento de Archivos
El sistema no lee, modifica ni comparte los datos almacenados en las nubes de los usuarios con terceros.
Acceso Externo
Ningún operador externo tiene acceso a las credenciales o bases de datos respaldadas.
